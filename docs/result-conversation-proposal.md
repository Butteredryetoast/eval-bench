# 结果与素材改版建议 · 2026-10-27

状态：仅方案，等待用户确认。本轮没有合并现有视图或改动结果详情交互。

## 一个案例结果入口

删除“按测试／按结果”切换，主区只展示结果卡片。顶部搜索和上传／导入保留统一尺寸。

一张卡片代表某次测试中的一个案例，其中可以包含多个 Agent 的独立会话。相同案例再次测试仍保留不同记录，不能按标题合并。人工导入也可以单独成卡，明确记录其来源。不同模型或重跑不会覆盖之前的会话与媒体。

卡片只显示：案例名、真实产物预览、Agent 图标及数量、执行状态、时间、已整理媒体数量。点击整张卡进入会话；移除卡片底部重复的“查看效果／整理素材”按钮。未产生可预览产物时显示实际状态，不放宣传图片冒充效果。

次级侧栏保留搜索与筛选，并提供测试批次列表。批次可以重命名、置顶；点击只筛选卡片，不切换到另一套列表。原运行记录和深链接继续有效。

## 卡片内部是会话工作区

推荐独立详情路由，关闭／返回后恢复卡片列表的筛选、分页与滚动位置。长对话、输入框和媒体面板不挤在一个小弹窗里。

- 顶部：案例名；当前 Agent 图标、模型切换；耗时、输入／输出 Token、对话轮数。多 Agent 时固定位置切换，禁止内容加载改变按钮锚点。
- 主区：初始提示词、逐轮回复和该轮产物；网页产物可打开实际预览，图片视频可直接看，代码和文件可展开。追问框固定在下方，继续当前原生 Agent 会话。
- 右侧按需打开“素材”：记录效果观察、截图、录屏／上传、裁剪压缩转 GIF、下载和素材列表。入口固定在详情顶部，卡片外不再重复。
- 复制在对应回复／产物旁；引用上下文和插入媒体分别采用明确操作，不把整个任务对象塞入正文。

指标显示当前 Agent 会话累计值，切换 Agent 同步变化。耗时采用已记录的实际执行时间，不含人阅读和等待输入的时间；Token 未上报显示“未提供”，已知部分标为“不完整”。对话轮数包含初始请求，失败重试单独计数。可展开逐轮明细。

原生任务有可续接的会话标识、Agent 在线且支持续聊时启用输入框。人工导入、老记录缺失会话标识、只返回静态产物的工具保留只读，提供“以此内容新建会话”，不伪装成原任务续聊。Agent 离线时保留内容及输入草稿，提供检查连接。

后端需补齐稳定 result/session/attempt 对应关系。现有实例用 attempt ID 标识，重跑与续聊后不能让媒体关联或文章快照随“最新结果”漂移。新卡片 ID 与会话 ID 分开，兼容旧 attempt ID。媒体按明确轮次／产物归属，不能把不同 Agent 的材料混在一起。

## 演示素材按案例分组

建议做“案例素材集”卡片，视觉类似文件夹，但先不引入可任意嵌套的文件夹体系。

每张卡以案例名称、2–4 张预览、截图／视频／GIF 数量呈现；点击后看该案例的全部已整理素材，可按 Agent、测试日期、轮次、媒体类型筛选。一个案例多次测试仍可汇总查看，文件保留具体结果和轮次来源。

人工教程没有案例记录时，可创建命名素材集；独立上传先放“未关联素材”，可稍后归入。缺失稳定 caseId 的历史素材按结果临时成组，不按同名标题自动并库。素材集是关联视图，不移动或复制原文件；在文章中已引用的文件不会因重新分组失效。

资讯可以只使用文字事实；实战文章可以从任意结果会话选上下文，再选已处理媒体插正文。录制与处理不是强制前置步骤，不阻碍先写大纲。

## 实施顺序

先完成稳定 ID／会话归属与媒体关系兼容，再实现卡片到会话详情、原生续聊及指标，最后增加案例素材集。始终保留旧深链接、重命名与置顶、人工导入、原始附件、现有文章引用和历史用量。先以原生多轮、多个 Agent、人工导入、失败与重跑四组场景验收，确认后再替换旧入口。
