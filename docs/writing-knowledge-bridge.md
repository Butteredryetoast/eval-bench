## 推荐运行位置

由同事维护唯一知识库和检索索引，他的电脑作为私有服务；本机网站通过可信私有网络访问。电脑需开机联网；休眠期间返回连接失败。若需要本机独立使用，再在本机单独准备 Vault、Python 环境、模型及增量索引，避免把另一台机器的路径直接填过来。

服务只开放 `/health` 和 `/context`，两者都验证 Bearer 凭据。默认回环监听，不新增公开生成接口。通过私人网络隧道接入回环服务，或仅绑定受防火墙控制的私有网络地址；勿直接暴露公网端口。原迁移包未鉴权的 API 入口不作为此集成的运行入口。

服务端在 `integrations/writing-retrieval` 安装其单独的 YAML 依赖，并配置：

```dotenv
WRITING_BRIDGE_TOKEN=至少24位的独立随机访问凭据
HOST=127.0.0.1
PORT=43130
OBSIDIAN_VAULT_PATH=/该电脑上的实际知识库路径
OBSIDIAN_LIBRARY_PATH=公众号写作结构库
RAG_ENGINE=haystack
RAG_PYTHON=/该电脑上的实际Python环境/bin/python
RAG_CACHE_DIR=/现有索引目录
RAG_MODELS_DIR=/现有模型目录
```

在该目录运行 `node context-server.mjs`，再由网站写作设置填写私有网络服务根地址和同一凭据。此时不需要 DEEPSEEK_API_KEY。已有 RAG 环境应复用其实际路径，不自动重新下载或重建全库。Haystack 首次索引可能超过请求等待时间，需在服务端完成；不回退静态导出或冒充空命中。

压缩包原文件与许可证保留；原 DeepSeek 推荐／生成／修订 API 和前端也保留作参考，但没有对外启用，不与主站端点冲突。本轮未连接、改动任何远端服务器，也未接触真实 Vault。
