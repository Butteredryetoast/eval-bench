# 猿大侠 · 热点监测

这是供编辑协作使用的本机共享工作区。热点、案例、附件及交接接口均免登录，任何能访问本站的人都可查看和编辑；编辑记录不自动发布到资讯RSS/API。

## 本机启动

需要 Node 24.11 以上。本项目已使用 Codex 自带的 Node 24.19；`monitor-local.mjs` 优先使用 `MONITOR_NODE`，其次检查 Codex 运行环境和当前 Node。现有系统 Node 22 不会被替换。

```sh
node scripts/monitor-local.mjs setup
node scripts/monitor-local.mjs start
node scripts/monitor-local.mjs status
node scripts/monitor-local.mjs restart
node scripts/monitor-local.mjs stop
```

`setup` 将 PostgreSQL 17.10 服务器及客户端工具安装在 `.data/`，不会注册系统服务。客户端从 PostgreSQL 官方源码下载并验证 SHA-256 后构建，首次准备需要网络和 Xcode Command Line Tools。setup也会安装前端测试所需的Playwright Chromium/WebKit。支持用 `MONITOR_SDKROOT` 指定构建 SDK。本机默认的新 SDK 与链接器不兼容，已使用现有的 MacOSX15.4 SDK，未改变系统默认 SDK。

实际网页为 **http://localhost:3002/admin/monitor**，API 为 `127.0.0.1:3003`。原默认端口3000/3001被现有SSH转发占用，因此没有使用它们。修改 `.env` 的 `WEB_PORT/SITE_URL` 与 `API_PORT/API_BASE_URL` 可调整；修改后使用restart重新启动应用。启动脚本会拒绝占用其他程序的端口。

热点台无需管理员密码。访问地址也记录在 `.data/local-access.txt`；采集凭据和数据库密码仍仅保存在后端，不得提交。数据库监听 `127.0.0.1:55432`，数据位于 `.data/postgres`。电脑关机或休眠期间不会持续采集。

## 使用流程

1. 热点监测：全部事件合并相同事件的报道，逐条动态用于核对每篇文章；精选仅展示通过本地独立评分的内容。AIHOT参考分始终单独保存。
2. 打开事件详情，核对主体、精确版本与发布时间；同事的分类尚未返回时显示待分类，也可人工确认选题。
3. 确认选题后搜索案例，分别寻找实践、对比、失败材料。检索方向不等于案例已经被证明属于该类型。也可粘贴原文链接。
4. 读取公众号正文，人工判断原作者实测或转述，核对版本、输入、工具和条件；把有价值的案例收入案例库。
5. 上传、拖入或粘贴截图，或主动选择窗口录屏。单个附件上限25MB；内置录屏最多2分钟、不录音。浏览器会要求你选择要共享的窗口，后台不会自动操控第三方页面。
6. 下载交接JSON或包含实际附件的 `tar.gz` 素材包，交给同事的分类项目、自测工作台。素材包上限100MB。

## 交接约定 v1

全部接口位于 `/api/admin/monitor`（沿用原地址），免登录且无需会话或CSRF令牌。写请求使用JSON，浏览器跨站写入会被拒绝；同站访问者共享编辑权限。异步操作建议带稳定的 `Idempotency-Key`。

- `GET /events/:id/export`：版本1事件包，含事件、有效报道、保存的案例、附件引用和自测结果。
- `GET /events/:id/bundle`：同一内容加实际附件的素材包，临时文件在下载结束后清理。
- `POST /classifications`：`{schemaVersion:1,eventId,category,angle,researchRequirements:[]}`。同一事件重复回写更新结果；页面导入时拒绝其他事件的ID。
- `POST /experiments`：`{schemaVersion:1,experimentId,eventId,caseId?,version,environment,input,output,conclusion}`。实验ID不得改绑其他事件，caseId必须属于该事件。第三方演示、团队实验与编辑判断分开记录。
- `POST /events/:id/search`：`{platform:"wechat"|"x",role:"example"|"comparison"|"failure",query}`。仅已确认的选题可提交。返回任务ID，候选不自动收入案例库。
- `POST /cases`：`{eventId,url,title,summary,author?,publishedAt?}`。原文URL规范化去重；重复发现保留稳定ID、保存状态与编辑备注。
- `PATCH /cases/:id`：编辑备注、条件、版本依据、案例用途与审核状态；改变事件版本会使已有案例的版本核对失效。

导出前删除凭据字段和URL中的临时认证参数；需要认证的媒体使用实际归档文件交接。JSON附件路径是本机素材接口，离线交接应选择素材包。

## 中文、低成本筛选与人工交接

列表优先使用AIHOT已有中文及同一事件的中文报道。Chrome可用右键网页翻译辅助阅读；这不消耗本站DeepSeek额度，但不会把译文存入数据库或导出文件。需要保存中文时，可在详情按需调用AI翻译与评分，原文仍保留供核对。来源摘要到刷新时间会显示“摘要正在更新”，系统继续核对来源，不代表新闻失效或素材被删除。

评分分三层展示，不能混成同一个分数：

- 免费规则初排：基于近48小时新进展、官方入口、多发布方报道、内容形式和明显促销词，给出优先看或观察，并显示理由；不是AI评分或事实核验。
- AIHOT参考分：保留上游分数与精选标志，不覆盖猿大侠自己的判断。
- 猿大侠评分：人工填写五维分数，或点击后由模型按原有权重独立评两次；不修改既有精选门槛。同步新闻不会自动批量调用模型，列表每次最多手动处理10条。

模型选择DeepSeek Flash。私有文件 `.data/credentials/models.env` 填 `DEEPSEEK_API_KEY` 和 `DEEPSEEK_BASE_URL=https://api.deepseek.com/v1`；步骤 `MONITOR_SCORE_MODEL` 与 `MONITOR_TRANSLATE_MODEL` 选 `deepseek-flash`。本机DeepSeek Key现已配置，`MODEL_CALLS_ENABLED=true` 已启用并完成真实翻译与评分验证。模型默认按需调用，可在用量与预算中启用后台自动处理；密钥仅保存在本机后端配置。

人工交接入口 `/admin/monitor/handoff`：选择选题、核对从详情保存的写作类型和方向、勾选所需案例，下载或复制Markdown文字交接单；素材包也包含文字交接单和所选案例的实际附件。JSON仅作为同事程序的高级接口。未选案例的素材及案例专属实测记录不会混入本次导出。分类和团队实测都能直接用表单填写。

信源管理按公众号、X、网站/RSS、其他平台分组，可按七个领域、来源角色、验证状态筛选。初始领域标签标记为建议分类，不确定的保留待分类；人工修改后保存。已接入来源可直接暂停/恢复；RSS、公众号和X入口可用普通字段试采，高级JSON配置默认收起。


2026-10-21实测：Kling 4.0样例完成中文翻译及两次独立评分（均62分），3次成功模型调用共2726 tokens。评分回答复用已有回执，未重复付费生成；未达到原有门槛的样例保留在全部动态而不进入精选。翻译已具备独立JSON格式要求，评分不会因另一次回答未重复附带译文而失效，详情页可自动更新后台任务状态。

## 动态覆盖、日期与功能区

工作区的资讯流（`/admin/monitor/feed`）提供逐条报道、AIHOT精选和同步核对；日报汇总（`/admin/monitor/journals`）切换日报/周报/月报及最近30期目录。主题筛选和共享收藏统一放在选题台，不再另设主题快捷页。AIHOT报告保留明确署名，历史期号可手动读取，任务不调用模型。

热点监测按事件合并；逐条动态按文章/发现渠道计数。两者都支持标题搜索、领域、类型、平台、来源账号、发现渠道、发布日期/发现日期以及每页20/50/100条。顶部和底部均可换页和跳页。日期采用北京时间，起止日均包含；填写具体日期后覆盖快捷范围，发布时间未知时采用发现时间。事件时间线默认原文发布时间升序，未知时间放在最后，可切换降序；同一原文合并展示，但保留各个发现渠道。

AIHOT同步先处理最新动态，再分页核对最近7天的全部/精选，随后展开热点详情和读取报告。中途失败会保留已收录文章，明确报告部分失败；只有全部动态分页完整完成后，才据此处理近期报道撤回。上游滚动接口不提供7天以前所有普通动态的完整历史，本机存档不能等同于全站历史。电脑需保持运行且数据库、worker均正常才会持续同步。同步和打开页面不直接触发付费评分；开启自动处理后，独立后台计划会为符合范围的新事件提交评分。

本机数据库重启时仅在首次使用、缺少PG_VERSION时初始化；已有数据库直接启动，不重新执行initdb，不删除已有数据。

2026-10-21 实机核对：本轮24页、2,120个上游文章ID在本机活跃记录中均可找到；这个核对只证明该轮公开接口返回的数据已入库。最新三条AI领域资讯通过worker完成DeepSeek双次独立评分（6次回执、5,653 tokens）：AMD/英特尔PyTorch合作63.5，Amodei安全立场回应39，EverOS Cloud 55。两套上游/本站评分分别保存，未更改精选门槛。

## 推荐过滤与助理初标（2026-10-21）

以前模块直接接收自采原始记录，未应用框架的预筛结果，未知主题还会默认归AI，导致综合科技源占据首页。现在未知主题保持“待归类”，对未人工确认/分类的既有记录重算规则分类，保留编辑指定领域；自采记录同步框架最新修订的相关性判断，明确BLOCK的内容不推荐。

首页默认“推荐候选（已过滤）”：有效助理/编辑建议、达到原门槛的独立评分、上游精选，以及明确AI创作/一手发布线索。促销、配件、配色和范围外信息过滤，例行更新、争议、预告及证据不足信息进入观察池。免费规则只作候选，不冒充AI判断或事实验证；原始动态保留，未改变五轴权重和门槛。规则写在industry/monitor-policy.ts；正式精选仍需原双次评分和人工核对。

本次24条助理初标（5建议写、11不建议写、8观察）见research/editorial-samples-2026-10-21.md和页面“查看助理初标与理由”。机器可读材料在私有.data/editorial-samples.jsonl。它们不是用户金标，不用它们擅自调整门槛。详情可保存编辑标注，覆盖助理意见；材料更正后旧标注不再用于推荐，标注不会变成数值评分，也不会自动确认选题。

AIHOT实时核对视图按最新完整动态分页的上游位置排序，而非用原文发布时间猜测上游顺序；可切回发布时间/发现时间。最新页检查显示检查时间、上游最新发现时间和该页未入库数量。新增报道记录本机首次入库时间；旧记录未曾记录的时间不伪造。关闭或休眠期间仍不会采集，页面的“0未入库”只说明该次已检查的最新页，不保证未来没有延迟。

动态与推荐页每60秒只读刷新，切回可见标签页时立即检查；正在输入、选择或编辑时不刷新，不提交采集或模型任务。此前任务结束后列表停止刷新，浏览器长时间停留会看到旧内容；升级前已打开的页面需要完整刷新一次以加载新的前端代码。

阅读版式统一了筛选控件的标签和高度，默认展示常用条件，日期/账号/排序放入可展开区域；来源、领域、内容类型、上游参考分和本站判断采用不同标签样式。未知领域使用中性色，标题与摘要增大字号及对比、限制行宽，阅读与原文操作单独排列。帮助、标准和运行状态默认收起，不占据主要阅读区域。

列表标签分别显示AIHOT参考分、自采文章评分与本站事件的AI/人工评分；未取得分数时显示待评，不混用上游分。事件聚合页的自采文章分显示有效自采文章中的最高分，正式事件评分另行显示。逐条动态和事件列表右侧提供“翻译”“打分”，按需提交原有worker队列；处理中禁用重复操作并显示进度，缺模型凭证时禁用，保留已有人工评分（可进入详情调整）。手机上按钮移至每条资讯底部，避免挤压正文。


## 统一工作区与入口清理

浏览器访问根地址`/`进入选题台；旧版首页、资讯、热榜、收藏、主题、日报和说明页统一跳转到新工作区对应页面。旧文章/事件链接尽量根据本机已存的出处关联打开事件，未匹配时进入存档资讯流，不凭旧ID创建新闻。框架的采集、发布读取层、机器接口和受保护的管理API仍供底层运行使用，不删除新闻、案例、素材、收藏或评分数据。

主导航仅保留选题台、资讯流、日报汇总、案例工作台、信源管理与使用说明。热榜、已确认与收藏是选题台内的视图。案例工作台分为寻找案例、案例库和交接导出，切换步骤保留eventId。写作方向仅在事件详情编辑，交接时核对同一份结果；素材包、文字交接单和高级JSON出口统一在交接步骤，详情不再重复放下载按钮。

已移除独立主题快捷页、重复的原生报告入口与最近10条批量AI处理按钮及对应`/process`接口。单条翻译/评分继续使用既有队列，没有独立批量状态需要迁移。部署入口调整使用模块自带redirects，原框架渲染测试使用独立基础站声明，当前安装站点另有真实重定向与案例步骤测试，均连接本地假服务。

旧后台跳转规则明确排除工作区的.data只读请求；工作区布局提供自己的加载失败页，重试与返回都留在同一工作区。安装站点测试覆盖选题台内部切换、后台只读请求和加载失败恢复，避免旧站跳转影响自动更新。

## 规则透明、来源分页与扩展平台

“规则与标准”页面`/admin/monitor/rules`通过只读接口`GET /api/admin/monitor/rules`展示实际权重、来源门槛、48小时时效参数、关键词正则、当前模型名、案例查询词/时间参数及新来源默认轮询间隔。参数由实际执行模块读取，页面不另抄一套。选题台每个视图有就地说明，视图可以重叠；推荐候选不是已验证效果，本站精选按事件保存门槛筛选，助理标注不改数值评分。

案例步骤解释候选来源和人工采用条件；寻找案例仅展示未保存候选，保存后进入案例库，避免两处重复显示。当前公众号关键词搜索取第1页，X按Latest并包含回复（2026-10-26起），两者均不做自动效果质量排名。检索意图、实际案例类型、版本匹配、作者实测、人工检查与团队复现分别记录。公众号发布时间标记及X的UTC日期规则在标准页列出；搜索回执继续复用原10分钟时间桶，未更改既有付费请求身份。

信源目录按平台独立展开和分页（每组20/50/100），分页参数为`page_平台名称`；更改筛选时回到各组首页。搜索支持名称、别名、账号、目录/采集配置ID及入口地址。目录数量按归一化入口计数，接入/启用/活跃数量按采集配置ID去重；活跃只统计启用且本站近7天有实际采集文章的配置。已存在的RSS/账号配置通过明确相同入口关联目录，不因名字相似自动合并。

`POST /api/admin/monitor/catalogue`登记新候选，保存到模块现有hm_source_checks，`registered=true`，重启后保留。登记不发起采集或付费请求；相同规范名称/X账号或明确相同RSS入口返回已有记录，试采成功后才通过原有接口启用。新增候选支持平台、类型、原文示例、账号/订阅入口、领域、角色和分级；凭据字段不能填在来源配置中。

“添加信源”和“围绕事件全网搜索案例”是不同能力。现有专用适配器支持公众号及X；RSS/网页/JSON可用于有明确公开或获准入口的新闻采集。小红书、微博、抖音、B站、YouTube可先登记入口及手工保存案例；没有经试采验证的适配器时不显示已自动接入。接更多平台时先拿到具体API文档与授权方式，分别实现采集或案例搜索的数据映射（URL、标题、作者、日期、摘要、媒体），接入后端凭据、回执与预算，并用本地假服务测试后再少量真实验证。

## 六种采集方式与外部脚本

管理界面支持框架原有六种方式：`rss`、`web_list`、`json_list`、`x_search`、`mp_account`、`external`。平台分类与采集方式独立；目录可单独按采集方式筛选，“仅登记”表示未选定采集方式。信源管理与标准页共用六种方式的适用范围、配置与费用说明。

外部脚本来源先登记为`external`，展开来源卡片取得稳定sourceId和JSON示例。后端在`.data/credentials/auth.env`配置至少16位随机`INGEST_TOKEN`，保存后重启本机服务；脚本端保存相同令牌。脚本调用既有`POST /api/ingest/items`（同源代理可用），带Bearer令牌与JSON，详见[推送接口](sources.md#外部推送接口)。网页不读取或显示令牌，不另建免鉴权推送入口。

首次推送建立隔离来源；隔离接收不等于已启用自采。点击“核验已收到的推送”只检查数据库中该来源经ingest收到的、包含标题/HTTP链接/有效发布日期的文章；缺日期或空推送不通过。核验成功可保留隔离，勾选启用时通过原有source更新接口转为editorial，之后由自采同步纳入工作区。暂停来源后既有推送接口返回409。已接入拉取的来源不可直接切换external，应单独登记脚本入口，避免混用身份。历史文章仍遵守统一时间与回填规则，推送判重不生成额外独立事实证据。

`external`是接收方式，不包含平台采集脚本，也不提供平台专用案例搜索。接收接口本身不调用模型，后续处理沿用worker、凭据、回执与预算机制；第三方采集服务的费用另计。

目录中的接入/启用/活跃统计可点击查看对应记录，筛选额外支持已接入、启用中、已暂停与尚未接入。

## 多平台案例收集

案例工作台统一识别X、Reddit、YouTube、公众号、小红书、抖音、B站、微博与网页。已存为web的旧案例按原文域名呈现平台，不删除、迁移已有素材。公众号和X保留现有自动关键词搜索；其他平台提供带关键词和检索意图的搜索链接，明确标注手动收集/自动API待接入。打开搜索是用户主动导航，结果不会自动回传本站。

“多平台批量收集”接受分享文案或多行HTTP链接，客户端预览平台数量，`POST /api/admin/monitor/cases/import`接收版本1案例包；同事工具可用`POST /api/admin/monitor/cases/ingest`，沿用已有后端INGEST_TOKEN鉴权，未配置/无效令牌一律401。两个入口都要求已确认选题，每次1–50条，整包校验成功才写入，严格拒绝未定义字段（不能导入saved、reviewed或已验证状态）。该接口不调用模型或第三方API。

案例包格式：`{schemaVersion:1,eventId,intent:"example"|"comparison"|"failure",items:[{url,title?,author?,summary?,publishedAt?,media?:[{kind:"image"|"poster"|"video"|"link",url}]}]}`。媒体链接默认candidate，不伪装已下载；日期未知保持null。原文链接规范化后按事件去重，重复导入保持已有标题、备注、保存状态、版本核验和媒体。返回created/existing/duplicates及caseIds。短链接与长链接在未解析前仍可能分别存在，需要人工核对。

候选与案例库分别按平台筛选并显示数量，候选需点击收入案例库才交接，所有平台都可上传图片与用户主动录屏。公众号正文/视频详情按钮仍只作用于公众号，其他平台没有解析器时不会错误套用公众号接口。

接口核查：极致了官网公开页面链接到[微信接口文档](https://s.apifox.cn/410674f9-f451-4b4f-957a-5f54f243bc83/220474677e0)，已见公众号与视频号说明；本次未取得B站、小红书、微博、抖音专用搜索API的可核实参数和响应，不能仅凭官网列出平台名就认定现有Key可用。后续拿到实际接口后仍须经后端回执与预算接入，再少量试采验证。

### 案例搜寻优先级与采用标准

编辑搜寻顺序：X、Reddit优先，其次YouTube与公众号，再补充小红书、抖音；B站、微博、网页保留。研究页默认X，排序不等于已接通接口或按质量排序。Reddit支持reddit.com及子域名/redd.it链接识别，平台搜索按new排列；帖子与具体评论永久链接分别保留，不自动抓取整串评论，不将多个回复视作多个独立实验。英文平台的手动检索意图补review/comparison或failure/limitations关键词。

标准在寻找案例与规则页就地展示：主题与版本对应、优先原作者亲测、具体任务与输入输出、提示词/代码/测试条件，以及失败边界。宣传结论、模型自评、搬运或缺版本材料先作线索。热度不是证据质量；目前标准由编辑核对，系统没有自动质量评分或自动观看视频。API搜索可带回已实现适配器返回的文字及元数据，手动/批量只保存链接和填写内容；媒体候选、实际归档、作者实测及团队复现状态保持分离。

Reddit自动搜索尚未接入；须先核实[官方API访问要求](https://support.reddithelp.com/hc/en-us/requests/new?ticket_form_id=16510899084308)及凭证。界面不会把平台搜索或脚本导入伪装成本站自动搜索。

### X与Reddit接入操作

研究页和使用说明共用「接通X和Reddit」指引，实时显示X凭证是否已填写；配置存在不等于接口已成功调用。运营者在[SocialData](https://socialdata.tools/signup)注册/登录并创建Key，在信源管理的API配置页填写，或写入项目`.data/credentials/collectors.env`的`SOCIALDATA_API_KEY`，后续请求热读取。Key不读回页面、不进入聊天、案例、日志或导出包；所有X搜索继续走已有回执和预算。充值需要运营者自行完成。

Reddit自动搜索仍未接入，因为实际API权限及内容保留/删除条件需要先落实。申请草稿在`research/2026-10-22/reddit-api-access-request.md`，由运营者核对真实用途后自行提交。不能把公众号编辑用途填成学术研究；申请没有获批前不宣称已连接。拿到允许的范围后再实现OAuth、限流、删除同步与后端适配；不先增加无用途的Reddit环境变量或凭据输入框。

### 本机VPN虚拟DNS与X连通性

2026-10-22真实验证发现，Shadowrocket的DNS将api.socialdata.tools和aihot.news解析为198.18.x.x虚拟地址，被原有私网防护正确阻止。系统监听的HTTP代理为127.0.0.1:1082，已在本机私有.env设置EGRESS_PROXY_URL；没有修改VPN、系统DNS或ALLOW_PRIVATE_NETWORK_FETCH。端口若随用户代理设置变化，需要按实际端口更新，不能把1082当成框架默认。

SocialData改为遵循已有egress路由：代理内DoH解析真实公网IP、校验后CONNECT固定地址，TLS主机名和认证重定向限制保持原样。未配置代理的部署仍走直接连接。真实guardedFetch访问SocialData与AIHOT均返回HTTP 200；带Key的案例搜索已到达SocialData，但返回HTTP 402 / Insufficient balance，未产生新候选。需运营者自行补充服务余额后再次验证；配置存在、网络正常、余额足够、取得候选分别是不同状态。

第一次私网预检拒绝的回执因框架保守策略记为unknown；已核对错误发生于assertPublicUrl、尚未进入HTTP发送，通过既有releaseReceipt记录billed=false和明确依据后恢复，未跳过回执或预算。后续402保留为供应商拒绝记录，不作为案例成功。

### 不调用模型的案例筛选与材料核对

寻找案例和案例库均支持关键词、平台、版本状态、证据来源、人工检查、收集方式和待补字段筛选；关键词按空格拆分后逐词匹配标题、摘要、作者、原文链接、版本依据、条件和备注。默认最近收集优先，可按已知发布时间排序；未知时间在后，以案例ID稳定排序。每页20/50/100条，上下均有分页和跳页，更改筛选回到首页，保留eventId，筛选不触发采集或模型。

`GET /cases?browse=candidates|saved`返回当前页及caseList计数；先按选题/保存状态取完整范围，再筛选、排序、分页，不再截断前500条。平台数量按当前选题下全部未保存候选或全部已保存案例统计，筛选后数量另列。旧读取/导出同样不再隐式截断500条，历史数据不删除、不回填新状态。页面附件仅返回当前页案例需要的附件，交接导出仍按实际选中案例读取。

材料核对只检查标题、作者、有效发布日期、版本匹配状态、条件是否填写、实测身份是否标注、人工检查与本机附件。媒体候选/封面不算已归档，文字案例可忽略附件项。字段存在不代表内容正确，版本字符串匹配不是效果验证，作者实测不是团队复现，清单不生成或覆盖质量分数。

## 模型用量与每日预算

`/admin/monitor/usage`统计最近7天本站`monitor_score`、`monitor_translate`回执，显示请求尝试数、输入/缓存/输出Token、预计费用及无用量回执数。只读页面不触发模型。默认每日5元，自动范围默认关闭；用户可选推荐候选或全部相关事件，并选择是否翻译标题摘要。只处理开启后收到、近24小时发布且非回填的报道；历史和已过滤事件不自动处理，手工评分保留。每分钟派发最多20个符合条件的任务，按材料指纹复用任务，已翻译且原文未变的条目跳过。关闭自动范围会阻止尚未开始的自动任务；不撤销已发送请求。

预算适用于模块worker中的手动及自动评分/翻译，不含框架文章处理、公众号和X采集费用。当前只支持DeepSeek Flash及官方旧别名，2026-10-23定价按高峰每百万输入未缓存2元、缓存0.04元、输出8元保守估算，非官方实付账单。其他模型需先实现对应计价再开放。调用前用UTF-8字节上界、提示词余量及最大输出预留，两轮评分一起预留；数据库事务锁防并发超额。零预算暂停调用；额度不够的任务标为等待预算，次日或修改配置后重新排队，自动任务仍需满足当前范围与时效。

`0102_hm_model_reservations.sql`新增预留记录，不删除旧数据。预留在明确完成/拒绝后释放；pending/unknown回执或进程中断可能已扣费，保留预留跨日等待核对。此时页面剩余额度保守偏低，禁止直接清空预留当作退款。费用表缺用量的请求不假定为免费。官方价格变化时需更新估算参数与说明。


## 便捷选题与收集流程（2026-10-25）

最短路径为「选题台→确定并找案例→只搜选中词→勾选链接直存案例库→交接」。选题台支持跨页勾选最多50条，复制文字清单、下载TXT或UTF-8 BOM CSV，保留摘要、关注理由、写作方向、原始出处和稳定ID，不自动确认选题、不调用模型。表格转义公式开头；过期/撤回摘要和认证参数沿用安全导出规则。

案例页优先展示当前选题、共用关键词及X/Reddit/YouTube/公众号/小红书/抖音搜索链接；更多平台与付费接口搜索保留高级入口；标准和连接说明由标题旁弹窗查看。检索词在失焦时写入URL，平台与意图一并随案例流程、侧栏入口保留，不发起自动付费搜索。打开第三方搜索后仍需复制链接回来，不能声称已自动读取帖子或评论。批量导入显示链接预览，可取消不需要的材料，直接保存或先放候选；可备注视频时间点和发现价值。外部脚本仍只能进候选，重复导入不覆盖既有备注/核验状态。案例保存后自动提取标题、作者、原文时间、封面与摘要；必要时在可选修正区修改，不自动标核验。文字、JSON和素材包共用所选案例范围。

`启动热点监测.command`在Mac上双击可启动既有本机服务并打开选题台；关闭终端不会停止后台服务。休眠、关机仍不能持续采集。页面显示最近核对时间；每日对照快照见research/2026-10-25/aihot-coverage-and-sources.md，不能用停机后的集中补收推导持续运行时延。

本轮补全Conductor、vLLM、ElevenLabs和Midjourney既有候选的官方RSS配置，未重复新增名称；均已通过本站试采并保存验证结果，尚未启用。原始RSS解析数不等于本站入库数，Midjourney最新条目不在近7天内，不能标为近期活跃。


## 白底彩色工作区与弹窗说明

工作区统一白底，蓝色用于主要操作，紫色、青色、橙色辅助区分内容与状态。选题台的推荐候选、观察、已过滤、本站精选、全部事件、热榜、已确认和收藏移入桌面左栏二级导航；手机通过左侧导航抽屉切换。导航、H1与浏览器标题共享同一视图映射，保留原mode/state语义；切栏目清分页，已确认/收藏仍查全部存档，清除筛选不会退出当前栏目。

选题标准、运行状态、栏目解释、使用帮助均由按钮打开弹窗，不再向下展开推走列表。标题旁只留短注释；说明与状态详情不占首屏。异常仍在运行按钮上显示「需关注」。案例标准、平台接入、材料标准和处理记录也使用同一弹窗。弹窗复用框架useModal，包含焦点循环、Escape关闭、回到触发按钮和背景滚动锁；关闭后保留筛选与选题勾选。平台分组、筛选表单和材料编辑等操作性折叠保留。

浏览页面、切栏目、打开与关闭弹窗只读取已有数据，不发起评分、翻译或付费搜索。原有/rules与/help页仍可直达。

## 案例关键词与平台搜索适配（2026-10-26）

`modules/hot-monitor/case-search.ts`为网页入口与后端X/公众号API共用的纯规则：优先材料中确实出现的已填主体，其次发布语句中的产品名、已知产品、作品名；不认识时提取短词并提示核对。版本限于主体旁的型号/版本，或已填且在当前标题摘要出现的字符串，不把数量、成本、票房、参数规模当版本。提取建议不回写成已确认主体/版本，不调用模型。多主体/汇总标题提示用户选择研究对象。基础关键词可编辑，最多140字符，不自动用新建议覆盖手工词。

平台适配共用主体、版本、任务与意图。X使用OR意图组和since（已知发布前一天，未知回溯7天），包含回复，接口仍为Latest；Reddit使用AND/OR、相关性排序，不套X的日期操作符；YouTube网页为普通短英文检索，不伪装API日期参数或硬编码sp；公众号、小红书、抖音等使用短中文词。默认仅关键词，不加入用途、任务、日期或别名；用户主动选用途后，精准模式才加入当前标题的任务和用途，放宽模式移除自动版本、任务、用途与X日期条件，手动输入的词保留；手动改词后不强加原标题的任务。页面可见每个平台的真实检索词，可复制；公众号手动入口为搜狗，与极致了搜一搜的覆盖不同。

意图只需选择一次，粘贴收集沿用该值；它不代表案例效果已核实。修改意图/精度保留手工关键词，切到整理和交接也保留上下文。默认只打开平台网页，不发起后台付费搜索；接口按钮需用户点击，继续走既有回执与预算。

交接页面先展示当前题目和案例勾选；复制和TXT为日常入口，素材包包含纯文字交接单及本机图片/录屏，Markdown/JSON进入高级格式。TXT与Markdown、JSON、素材包共享案例选择，空选择仅交接事件；预览按所选案例只读生成，切换选择取消旧请求。文字交接附提取关键词、警告及X/Reddit继续搜索入口；长段内容节录并提示完整内容在案例库。选题清单TXT/CSV也附案例搜寻词。

平台语法依据：[SocialData操作符](https://docs.socialdata.tools/resources/twitter-search-operators/)、[Reddit搜索语法](https://support.reddithelp.com/hc/en-us/articles/19696541895316-Available-search-features)、[YouTube网页筛选说明](https://support.google.com/youtube/answer/111997)、[极致了搜索](https://s.apifox.cn/410674f9-f451-4b4f-957a-5f54f243bc83/454005291e0)。网页参数并非稳定API契约，不能宣称结果覆盖完整；本轮只核对参数和本地假服务，未提交真实付费搜索。


手动刷新入口同样使用弹窗：点击「刷新新闻」先只读展示上次动态检查／同步尝试时间及同步任务，点击「开始刷新」才提交原有同步队列。排队或运行中禁用重复开始，页面可见时自动只读更新进度。关闭或Escape退出不取消后台任务，页面勾选和筛选保留。入口继续使用原有分钟级同步去重，不新增采集或模型调用路径。部分同步失败的尝试时间不标成「完整核对」。


## 标题选字、搜索方法与日期预览

案例页完整标题显示为可选字格：中文按grapheme逐字，英文和型号整体成格，标点只展示；选择按原标题顺序生成关键词，相邻片段连写，分开的片段以空格隔开，仍受140字符基础词限制。可直接改输入框或恢复自动关键词。URL保存keywordSource=auto/manual/title，标题点选和手动词在放宽时保留，不再因恰好与自动词相同而被当成自动版本移除；前后端使用同一来源标记。

「搜索关键词的方法」放在自动提取备注前，以弹窗解释空格、AND、OR、括号、引号与since的区别。框内只需主体/版本/任务词，平台语法由系统适配；普通平台空格并不保证严格同时匹配所有词。选字与说明弹窗只读，不调用付费接口。

切换选题先按北京时间原文发布日期列日期和计数，鼠标停留、键盘focus或手机点击预览当天已确认题目，点具体题目才切换。日期未知单独列出。GET /api/admin/monitor/topics?date=YYYY-MM-DD|unknown&currentId=...只读返回已确认及当前题，摘要沿用过期/撤回处理。日期目录随cases返回topicDates，不截断日期；同日请求缓存，快速悬停合并请求，旧响应不覆盖新日期，失败可重试。预览不清空正在编辑的关键词或粘贴链接，切换题目时才清旧搜索上下文。


## 分组折叠导航与工作区减负

左栏分「工作／信息／其他」，工作区最上方为选题台与案例工作台；资讯流、报告在信息组，来源、规则、费用和说明在其他。首次进入一级收起，点击才显示二级，同时只展开一个；实际选页面后展开当前所属一级。所有原横向页面导航移左，案例三步骤、资讯三个视图、日报周报月报不再在正文重复显示。手机用左侧抽屉，关闭后保持原位置与编辑。案例上下文在本组件生命周期内跨栏目保留，无需浏览器收藏或重复选择。

案例搜索增加keywords默认意图：只使用输入框中的词，X不加OR用途组、since或别名，YouTube与中文平台不加案例/demo等后缀，Reddit仅用AND组合所选词。优化条件需用户主动选用途；前后端同一逻辑，旧记录里的已选意图保留。手动粘贴以直接保存案例库为主要动作，回车默认同样直存；暂存入口收在更多保存方式。无待挑选结果且无筛选时，整块列表/筛选/分页不显示；有结果时默认收起，有筛选时保持可清除。

「待挑选结果」是自动接口或外部脚本返回的素材暂存区，已经存在数据库但未被编辑采用；不是第二份案例库。手工挑好的链接无需再走暂存。已有结果和备注不删除，不自动标为实测通过。

事实报道与时间线改为默认关闭弹窗，按已有数据本地切换顺序，不跳页或丢失编辑。详情保留核心事实与判断，标注编辑及自测放低频弹窗；分类表单不再重复展示相同写作方向。案例库使用紧凑缩略图列表，当前选题条代替反复选题下拉；切题在研究/案例库/交接共用日期选择器。旧/rules、/help、单条程序保存接口仍保留，删除的是重复的手工表单入口，不删除用户资料。


## 案例原文信息自动提取

编辑将链接直接保存到案例库，或在待挑选结果点击收入案例库后，自动排入公开信息提取任务；外部脚本和未采用候选不自动访问。后台经现有出网保护读取HTML的Open Graph、Twitter Card及JSON-LD，YouTube、X使用官方公开oEmbed。自动填写原标题、作者、原文摘要、明确含时区的发布日期及封面候选链接；不调用模型，也不下载图片或视频。公众号公开页实际返回验证页时，使用已配置的极致了article_detail接口自动补全，经原paidRequest回执与采集预算计费；链接不完整时不发起付费请求，其他平台不自动转付费接口。X公开oEmbed通常只有帖文，封面缺失保持部分信息；动态网页、登录验证、接口限制等显示具体原因。失败仍保留已保存链接，可重新提取，不要求补写标题。公众号另保留显式全文读取按钮，用于主动重新读取原始字段，同样经原回执和预算机制。

提取状态与内容保存在案例JSON中，无新增数据库迁移。重复保存不会重新排队；主动点击重新提取可重试。后台完成时只填空字段和待补标题，合并新的媒体链接，保留人工标题、摘要、备注、审核及实测判断；前端修正原文信息收进可选区，仅提交确实编辑过的字段。队列结果通过已有Jobs刷新，切页无需重新输入。封面链接仅代表网页提供了图片入口，不代表已在本机归档或已取得视频文件。

## 浏览器采集助手

Chrome/Edge的Manifest V3扩展源码在modules/hot-monitor/extension，站内「浏览器采集助手」提供ZIP下载。仅请求activeTab、scripting、storage和本机3002端口的host权限。点击工具栏图标后才在当前页显示Shadow DOM悬浮窗；两个主要动作是确认并提取当前页、回案例库。外站页面按实际标签页URL校验，采集当前可见的标题/OG封面/作者/描述和明确日期，不读取登录凭据。仅把页面提供的材料存为待核对案例，不把内容真实性自动标为已验证。

扩展通过已打开的本机工作台标签页执行固定的同源请求，只读取选题详情、导入一个案例。沿用原sharedHandler和案例导入接口，不新增跨站写接口、CORS白名单、公开推送Token或API凭证。确认保存不激活或导航本机标签页，只有点击回案例库才切换。归属选题来自工作台，保存前重新校验，选题已变化时要求在悬浮窗核对新名称后再点击。原页面元数据优先随链接传入，后台自动补提取仍遵守已有采集回执和预算。首次安装需用户在浏览器扩展管理页加载解压目录，扩展不发布到商店。

日期选题弹窗扩大并显示当前题；右侧改紧凑题目列表，可在当天题目中本地查找。悬停停留后才切换预览和发起读取，避免扫过日期产生空列表；日期外定位成功后更新计数。手机日期单行横向滚动，题目随弹窗滚动；选当前题不清搜索上下文，选择其他题才切换。

## v1.1采集会话与导航保持

研究页关键词区新增独立「安装插件／启动插件」控制块。localhost静态workspace.js负责只读安装检测，以及捕获本地页面原生可信启动/停止按钮。启动消息同步申请manifest列出的可选平台权限，随后核对已确认选题并注册auto.js动态内容脚本。用户首次在Chrome/Edge允许后，本次浏览器会话中X/Reddit/YouTube/公众号/小红书/抖音等已授权平台整页导航均自动展开浮窗；SPA导航保留已有浮窗。自动启动只显示面板，仍须点击确认才保存，不触发模型。

启用状态保存在chrome.storage.session，动态脚本persistAcrossSessions=false；worker休眠不丢状态，关闭浏览器后重置。停止时撤销动态注册并隐藏现有面板，已授予的平台权限保留以便下次启动；普通站点仍用activeTab手动打开。工作台消息只允许status/start/stop，严格限定本地3002端口与顶层页面；不开放任意网页指令或后端跨站写权限。安装包新增workspace.js与auto.js，旧版用户需在扩展管理页刷新插件并刷新本站一次。

进入、重载或从扩展返回research/cases/handoff，案例工作台二级导航保持展开；手动收起后仅改关键词不会反复展开，同路径切换选题会重新展开。选题台顺序按使用者确认调整为全部事件、推荐候选、热榜、本站精选、已确认、收藏、观察、已过滤。


采集助手的启动状态同时核对session与实际动态脚本注册。自动展开失败会记录boot_received/context_ready/injected/shown阶段，向工作台回报脱敏原因；诊断只存主机名与固定状态，不保存搜索词、文章路径或页面内容。扩展内容脚本初始化后主动宣告READY，修复React先探测、document_idle后监听时消息丢失而误报未连接的竞态。

X原帖采集会按当前status ID锁定文章自身的时间／作者链接，排除回复；标题摘要取原帖tweetText，作者和时间取原帖节点，封面取原帖tweetPhoto媒体或video poster，不使用X通用OG宣传图。帖子正文尚未显示时提示稍候而不提交。SPA变更地址或标题时更新悬浮窗页面说明并清除上一页已保存标记，不自动提交。

## 候选保留、评分更新与API配置

推荐候选与独立评分分开保存：一旦规则或编辑将事件加入候选，低分、重评或翻译不会自动移除。事件卡片右下方红色「取消候选」仅更改推荐资格，不删除原文、分数、已确认选题或案例；全部事件仍可「加入候选」。日期、领域和其他过滤条件照常生效。已有候选在升级时补写保留状态；原先因低分退回观察、但未评前满足规则的近期事件可恢复候选。历史资料不当作新候选补入。

评分/翻译任务在页面可见时每2秒只读检查，完成即更新卡片；无需打开运行弹窗或手工刷新。其余时间维持每分钟只读更新，不触发模型。所有一级导航的二级目录可同时展开，关闭某个栏目不会折叠其他栏目。

信源管理新增「API配置」。目前可编辑极致了和SocialData的Key及接口地址，未知平台仍需接入适配器。密钥只写本机collectors.env，不写数据库，不读回页面，不放日志和导出；空Key保留原值。更改服务主机需同时给出新主机密钥，保存不做付费测试。凭据按文件替换热读取，API与worker后续请求可生效；环境变量优先的服务明确只读，不能在网页假装覆盖。

## 2026-10-27评分与刷新恢复

运行状态会对照实际后台队列：已结束或已失去对应队列记录的中断任务归正为失败，不再永久锁住刷新按钮；仍在排队和执行的任务继续保留。此过程不自动重发付费调用，未知扣费结果的预算预留仍等待核对，不删除新闻和案例。

评分和翻译前先核对材料的新鲜度；AIHOT摘要过期时，在后台按已知公开列表入口重新校验相关报道，再预留预算和调用模型。更正采用新摘要；上游读取失败或无法确认目标仍可用时停止本次处理并显示原因，不拿过期摘要评分。页面打开和只读更新不触发这些请求。失败原因在资讯卡片按钮下显示，评分、翻译和同步进行中自动更新状态，恢复后可以直接重试。

本机代理访问Cloudflare DNS出现超时、同一代理访问Google DNS可用后，出站解析增加固定Google DNS备用。主服务查询失败才切换；返回的地址仍检查内网、保留地址及混合结果，并固定到已验证IP连接，保留原域名、TLS证书检查和请求总超时。不修改系统代理设置，不接受未验证的系统DNS结果。
