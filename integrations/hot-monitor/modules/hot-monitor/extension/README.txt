热点监测采集助手v1.1（Chrome／Edge）

安装一次
1. 解压hot-monitor-collector.zip。
2. Chrome地址栏打开chrome://extensions；Edge打开edge://extensions。
3. 开启「开发者模式」→「加载已解压的扩展程序」→选择含manifest.json的hot-monitor-collector文件夹。
4. 刷新热点监测网页。若已装旧版，在扩展管理页点击插件卡片上的刷新，再刷新工作台。

日常使用
1. 在http://localhost:43110/hotspots选好并确认选题，进入寻找案例，保持这个标签页打开。
2. 在寻找案例的关键词下方点击「启动插件」，首次允许浏览器请求的平台显示权限。
3. 从页面打开X、Reddit、YouTube、公众号、小红书、抖音等平台；打开文章、帖子或视频后，悬浮窗会自动展开。
4. 先核对悬浮窗选题名称，再点「确认并提取案例」。网址及页面已有的标题、封面等直接保存到案例库，缺信息时后台继续补全；当前网页不跳转。
5. 想整理材料时点「回到案例库」。停止本次采集时回工作台点击「停止插件」。关闭浏览器后，下次研究时再启动一次即可。

插件仅在你点开后读取当前页信息，数据保存到本机热点监测，不使用模型，不携带采集API密钥。公众号补读沿用本站已配置接口和采集预算。
目前连接本机43110端口；自动显示限于已授权的支持平台，普通网站仍可点工具栏图标打开。工作台关闭、服务未启动或没有已确认选题时不会自动显示。切换选题后保存前会再核对，防止归错选题。
