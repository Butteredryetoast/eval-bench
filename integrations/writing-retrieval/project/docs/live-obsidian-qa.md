日期：2026-10-26。按用户确认的「现有 Obsidian 知识库，后续更新能自动用于网页」替换静态导出读取。

## 已完成

- 正常 API 直接只读扫描 `/Users/mac/Documents/Obsidian Vault/公众号写作结构库`，没有向 Vault 写入文件。连接失败会明确报错，不回退历史 JSON。
- 每次搜索、匹配、状态检查重新检查笔记变化；只重读变动文件。可见网页每 15 秒更新状态和模板，聚焦窗口或打开设置/模板时也刷新。
- 读取全库原文与最高累计版本拆解，以文章 ID 合并。旧轮次不重复计入，最新版删除的拆解不会从旧轮次复活。2023 年前文章继续排除。相同 ID 的同类笔记按编辑时间选取并提示重复。
- 原文的旧自动分类说明不替代正文。模型接收有限的实际正文和拆解片段，区分候选与已拆解；普通方法笔记也可检索。
- 搜索结果显示真实笔记片段，Obsidian 链接对应片段所在文件。模板来自当前结构定义，成熟度由最新证据卡补充。
- 方向推荐记录知识库版本；确认后库变化会拒绝生成并提示重新匹配。用户已有草稿不会因知识库更新被覆盖。
- DeepSeek 密钥与知识库连接分开。搜索无需模型、无需密钥，也不会消费模型额度。

## 自动验证
